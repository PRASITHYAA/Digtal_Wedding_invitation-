Make the admin key

Run this on your own computer (double-click the file). Nothing is sent anywhere — the token is encrypted in your browser.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate. Repository access: only this repo. Permission: Contents → Read and write.
  2. Paste the token and choose your admin password below.
  3. Copy the result into GITHUB_TOKEN_ENC in config.js, then push.

Do not use a password that is shown on any public page. Anyone who knows it can decrypt the token and edit your repo. Never commit make-key.html output other than the encrypted line.
